# JAVA_introduccion_conceptos_java
Esto es un pequeño proyecto para enseñar programación en java a todo aquel que este empezando este libro sé ira actualizando en el futuro, con nuevas versiones y ejemplos. 

En este mismo proyecto se adjunta el archivo **Tetris.exe** el cual esta creado en base a Java como un pequeño ejemplo de lo que se puede lograr en la programación mi objetivo es que lo tomes como un proyecto de motivación para que sigas programando y aprendiendo más.
